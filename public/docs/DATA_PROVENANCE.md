# NEXORA Data Provenance

Every public metric resolves through `visual → metric → public export → transformation → snapshot → official source`.

Required metadata include provider, official URL, record or archive identifier, observation year, source period, retrieval and snapshot dates, source vintage, schema/pipeline/taxonomy versions, checksum, transformation hash, geography, unit, missing-value status and redistribution rule.

READY is reserved for verified public snapshots or controlled official records that pass the current quality boundary. Program objectives remain separate from observed outcomes.
