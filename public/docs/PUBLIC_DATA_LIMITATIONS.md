# NEXORA Public Data Limitations

- The provider catalog is broader than production-ready snapshot coverage.
- Publication counts do not measure innovation quality.
- BFS applications are not realized startups; BDS firm dynamics remain separate.
- ACS estimates require table universes and margins of error.
- Patent geography uses source-record addresses, not headquarters by default.
- Program objectives, announcements, funding and observed outcomes are distinct states.
- Data access does not imply unrestricted raw redistribution.
- No robust public private-capital measure is configured.
- Public infrastructure does not disclose or represent unpublished research designs.
