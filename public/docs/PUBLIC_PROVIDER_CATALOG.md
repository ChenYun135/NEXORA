# NEXORA Public Provider Catalog

Tier A covers OpenAlex, NSF Awards, NCSES HERD, SBIR/STTR, BLS, Census BFS, Census BDS, Census ACS, BEA Regional, USPTO, California Legislative Information, Federal Register and the Official Program Evidence Library.

Tier B covers IPEDS, USAspending, EDA Tech Hubs, NSF Engines, DOE programs, California Energy Commission and California GO-Biz.

Each registry entry reports the official URL, access type, authentication, reuse boundary, cadence, time and geography coverage, supported generic constructs, citation, operational state, verification date and limitation. See `/research/provider-registry.json` for the canonical machine-readable catalog.
