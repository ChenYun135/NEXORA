# NEXORA Research Data Expansion R2

R2 advances the public data foundation from a provider catalog toward bounded, reproducible longitudinal evidence.

Four Tier A provider families are currently marked READY within tested product boundaries: OpenAlex, BLS QCEW, Federal Register and the controlled official program library. The public operational window is 2015–2023 for the current longitudinal aggregates.

NSF Awards remains staged because full-result pagination did not provide stable non-overlapping pages in R2 QA. Census BFS, BDS and ACS remain not configured because current API access requires a key. No missing official value is replaced with a fabricated estimate.

Paper-specific panels, transformations, parameter candidates, model calibration inputs and diagnostics are excluded from the public release.
