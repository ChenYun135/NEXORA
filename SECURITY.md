# Security Policy

## Supported version

Security fixes target the latest NEXORA public release candidate or release.

## Reporting

Do not disclose a suspected vulnerability, credential, personal data, or exploit in a public issue. Until a dedicated security contact is published, report privately to the repository owner through the hosting platform's private security-reporting channel. Include affected version, reproduction steps, impact, and a minimal proof of concept; omit real credentials and unrelated personal data.

## Scope and guarantees

The public demo is designed for anonymous, read-oriented exploration. It does not require application accounts, store AI prompts in an application database, build people profiles, or intentionally collect private contact data. Hosting providers may still retain operational logs under their own policies. See [docs/SECURITY_PUBLIC.md](docs/SECURITY_PUBLIC.md).
