# Radar Opportunity Score Method / Radar 机会评分方法

The Sprint 3 prototype score is a transparent, configuration-driven composite. It is not an observed fact, prediction, valuation, or investment recommendation.

Sprint 3 原型评分是透明、配置驱动的综合指标，不是观测事实、预测、估值或投资建议。

| Dimension / 维度 | Prototype weight / 原型权重 |
|---|---:|
| Research Momentum / 科研动能 | 16% |
| Patent Momentum / 专利动能 | 13% |
| Startup Momentum / 创业动能 | 14% |
| Capital Momentum / 资本动能 | 11% |
| Policy Momentum / 政策动能 | 10% |
| Talent Momentum / 人才动能 | 10% |
| Market Readiness / 市场就绪度 | 9% |
| Technology Maturity / 技术成熟度 | 8% |
| Ecosystem Strength / 创新生态强度 | 9% |

## Calculation / 计算

Inputs use a normalized 0–100 prototype scale. Available dimension weights are re-normalized to sum to one. A missing dimension is excluded rather than assigned zero. The result reports the available original weight, each effective weight, dimension contribution, and missing evidence. When all dimensions are missing, no score is produced.

输入使用 0–100 的原型标准化范围。可用维度权重重新归一化为 1；缺失维度被排除而不是赋零。结果公开原始可用权重、有效权重、维度贡献与缺失证据。全部维度缺失时不生成评分。

Production normalization must define comparison cohorts, time windows, outlier treatment, coverage thresholds, source quality, and sensitivity tests before any factual ranking is released.
