# MVP Roadmap / MVP 路线图

1. Foundation (complete): shell, bilingual dashboard, domain model, demo data, provider boundaries, provenance policy.
2. Atlas: geographic industry model, region interaction, source-backed regional metrics, MapLibre evaluation.
3. Radar: signal methodology, time series, configurable opportunity scoring.
4. Ecosystems: graph exploration, entity pages, evidence-linked relationships.
5. Policy and AI: official-source ingestion, retrieval, citation-first copilot, evaluation.

1. 基础阶段（已完成）：应用外壳、双语首页、领域模型、演示数据、服务边界与来源政策。
2. 产业图谱：地理产业模型、区域交互、可溯源指标与地图技术评估。
3. 趋势雷达：信号方法论、时间序列与可配置机会评分。
4. 创新生态：知识网络探索、实体页面与证据关联。
5. 政策与 AI：官方来源接入、检索、引用优先的研究助手与评测。
