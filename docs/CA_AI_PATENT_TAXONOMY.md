# California AI Patent Taxonomy / 加州 AI 专利分类法

Version `ca-ai-patent-taxonomy-v1.0`; live status `NOT_CONFIGURED`.

Candidate CPC families: `G06N3/00`, `G06N5/00`, `G06N7/00`, `G06N20/00`, `G06F18/00`. These overlap and require fixture tests plus manual review. Applicant-name matches alone are excluded. Inventor, assignee and filing geography must remain separate fields. / 候选 CPC 家族存在重叠，必须经过 fixture 测试与人工复核；仅申请人名称命中不纳入，发明人、受让人与申请地理必须分开。

No production count exists until a server-side `USPTO_API_KEY` is configured and the live adapter passes quality gates. / 在服务器端配置密钥并通过质量门禁前，不存在生产级计数。
