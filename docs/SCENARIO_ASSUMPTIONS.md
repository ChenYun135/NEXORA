# Scenario Assumptions / 情景假设

All ten scenarios are prototype configurations. Parameter records declare group, unit, default, minimum, maximum, step, classification, source note, sensitivity range, and affected model channels. User changes are model inputs, not observed facts.

Research productivity has a derived-calibrated basis. Policy, commercialization, talent, ecosystem, market, delay, depreciation, and attrition parameters are assumption-led unless a record explicitly states otherwise. Advanced controls expose these assumptions; reset restores the selected scenario defaults.

No scenario may be described as predictive, optimal, guaranteed, or recommended. Outputs are deterministic consequences of declared equations and inputs.
