# California AI Network Empirical Method / 加州 AI 网络实证方法

Nodes are the 16 institutions resolved from the OpenAlex candidate frame. An edge exists only when an explicit two-institution AND filter returns a positive AI-subfield work count for 2015–2026. All 112 positive pairs remain in the snapshot; the UI promotes the 40 highest-count edges.

Degree and weighted degree are labeled “within current verified dataset”. No importance ranking, full California network or causal knowledge flow is claimed. / 度数与加权度均标注为“当前核验数据集内”；不主张重要性排名、完整加州网络或因果知识流。
