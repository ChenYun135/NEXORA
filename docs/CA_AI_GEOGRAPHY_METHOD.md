# California AI Geography Method / 加州 AI 地理方法

OpenAlex institutions must have `geo.region=California`; cities map to NEXORA regions by a documented deterministic table. The 2025 BLS source area `0041940` is San Jose-Sunnyvale-Santa Clara MSA and maps only as a **partial overlap** with `sf-bay-area`. NSF uses awardee-state CA and retains recipient city.

State, MSA, metro-ecosystem, awardee and performance geographies are never treated as interchangeable. / 州、MSA、都会生态、受资助地与履约地不得互换。
