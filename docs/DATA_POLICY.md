# Data Policy / 数据政策

NEXORA uses only publicly accessible, legally reusable, non-sensitive information. It excludes private personal, financial, employment, behavioral, confidential business, unauthorized profile, and unlicensed paid data.

NEXORA 仅使用公开可访问、可合法复用且非敏感的信息。禁止使用私人个人、财务、就业、行为、商业机密、未经授权的个人资料及无授权付费数据。

Every production record must identify one of three layers: `source_fact`, `derived_metric`, or `ai_interpretation`. Source facts retain canonical URL, publisher, access date, and license where available. Derived metrics retain methodology. AI output is visibly labeled and never overwrites source facts.
