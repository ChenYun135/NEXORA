# Model Changelog

## sim-model-v1.0.0 — 2026-08-10

- Introduced nine-stock innovation ecosystem model, twelve flows, four auxiliaries, explicit delays, diminishing returns, and four documented feedback loops.
- Added 26 versioned parameters and ten bilingual prototype scenarios.
- Added deterministic annual Euler solver for 5/10/15-year horizons.
- Added calibration classification, one-way sensitivity, uncertainty taxonomy, bottleneck rules, warnings, deterministic summaries, exports, and reproducibility metadata.
- Classified the model `PARTIALLY_CALIBRATED`: one observed-calibrated stock, one derived-calibrated stock, seven assumption-led stocks.
- Explicitly deferred Monte Carlo and empirical forecasting until defensible production distributions and outcomes exist.
