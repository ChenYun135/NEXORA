# California AI Public Funding Taxonomy / 加州 AI 公共资助分类法

Provider frame: NSF awards dated 2025, awardee state CA, API keyword exact phrase “artificial intelligence”. NEXORA deduplicates by award ID and retains titles matching: artificial intelligence, AI, machine learning, large language model, LLM, neural network, deep learning.

Amounts are nominal `fundsObligatedAmt` in USD. They are not annualized, inflation-adjusted, multi-agency totals or impact estimates. Recipient state is administrative awardee geography. / 金额为名义已拨付美元，不是年化、通胀调整、多机构总额或影响估计；受资助州为行政地理。
