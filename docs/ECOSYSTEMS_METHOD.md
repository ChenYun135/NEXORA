# Ecosystems Method / 创新生态方法

Sprint 4 is an explainable product prototype, not a verified directory or investment tool. The workflow is:

1. Select a region–industry context and fixed snapshot.
2. Apply node, relationship, layer, confidence, evidence, search, and technology constraints.
3. Build an undirected analytical adjacency view for connectivity metrics while retaining the original edge direction for presentation.
4. calculate metrics from the currently visible graph.
5. present evidence and Demo labels beside the relevant relationship.

Sprint 4 是可解释的产品原型，不是已核验机构名录，也不构成投资建议。所有关系均清楚标注为演示关系；未引入个人履历、联系方式、浏览数据或任何私密人物数据。

Curated clusters demonstrate research, commercialization, capital, and policy neighborhoods. They are not presented as algorithmically discovered communities. Comparison uses the same health configuration across contexts. Empty, missing, and insufficient states remain distinct from zero.
