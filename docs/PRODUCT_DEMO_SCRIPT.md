# NEXORA Product Demo Script / 产品演示脚本

Target: **6–7 minutes**. Use the private Owner-only site. Start in English, then switch to 中文 once to demonstrate persistent language preference.

## 0:00–0:45 — Home / 首页

State the promise: “NEXORA is an evidence-based future-industry intelligence platform.” Point to the connected journey and the explicit Demo evidence notice. Avoid calling prototype KPIs live market facts.

说明 NEXORA 是“基于证据的未来产业情报平台”。展示产品旅程与演示数据提示，不把原型 KPI 描述为实时市场事实。

## 0:45–1:30 — Public Data + Atlas / 公共数据与产业图谱

Open Data Status briefly: OpenAlex and World Bank are healthy, Data.gov is degraded with last-known-good behavior, USPTO and live AI provider are not configured. Continue to Atlas, choose a region, and open its evidence panel.

## 1:30–2:15 — Radar / 机会雷达

Follow the contextual Radar link. Show momentum dimensions, missing evidence and Demo Composite Score. Emphasize that the score is explainable and is not investment advice.

## 2:15–3:00 — Ecosystems / 创新生态

Open the ecosystem network with the selected technology context. Inspect a node and relationship evidence. Explain that organization-level public evidence is used and no private people graph exists.

## 3:00–3:45 — Policy / 政策智能

Open the policy landscape. Separate official public facts, derived classification and NEXORA interpretation. Mention that the module is not legal or regulatory advice.

## 3:45–4:30 — Organizations / 组织智能

Open an organization detail record. Show stable entity identity, source links, relationship claims and evidence status. Do not imply that Demo organizations are verified production entities.

## 4:30–5:30 — NEXORA AI

Ask a contextual question. Show evidence coverage, citations, gaps and “Why this answer.” State that no live model provider is configured; the current fallback is deterministic and evidence-first.

## 5:30–6:30 — Simulator / 情景模拟

Run a named scenario and compare it with baseline. Show assumptions, sensitivity, uncertainty, data gaps and reproducibility hash. Repeat: “Simulation is not prediction.”

## 6:30–7:00 — Close / 结束

Return to Data Status. Summarize the trail: **source → map → detect → connect → understand → discover → explain → simulate**. Future flagship slot: a California AI real-data case may later connect these routes, but no case data or public link exists in this release.
