# AI Citations

Citations can reference only items retrieved into the current `EvidencePack`. URLs must be HTTPS or an approved local documentation/data-status path. The validator rejects invented source IDs, unsafe schemes, duplicate citations, and claim/citation mismatches.

The UI presents source name, evidence status, observation date, geography, source URL, and related claim IDs. Citation order follows first use, not provider preference. Missing sources are reported as gaps and are never represented by synthetic citations.
