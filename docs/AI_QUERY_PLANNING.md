# AI Query Planning

Query understanding performs length limiting, language detection, intent classification, stable entity resolution, context merge, ambiguity detection, and safety screening. Supported intents cover technology, trend, evidence, policy, ecosystem, organization, comparison, methods, data availability, briefs, source verification, and cross-domain research.

The planner is deterministic and versioned. Plans include required/optional operations, entity IDs, metric keys, time window, item limits, and retrieval version. Ambiguous geography and unsupported requests stop before evidence synthesis.
