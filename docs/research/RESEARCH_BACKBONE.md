# NEXORA public research backbone

NEXORA separates evidence and inference into four layers:

1. **Observed** — attributable public records or official aggregates, stored with provider, retrieval date, geography, period, license/terms and snapshot hash.
2. **Derived** — reproducible transformations with formulas, denominators, mappings, version and lineage.
3. **Analytical** — descriptive comparison, networks and interpretation. These views do not imply causal identification.
4. **Simulation** — conditional trajectories generated by explicit stocks, flows, feedback loops, delays, policy inputs and assumptions.

Every research-facing output should expose its evidence class, status (`AVAILABLE`, `PARTIAL`, `STALE`, `UNAVAILABLE`, `NOT_CONFIGURED`), relevant snapshot/model version and limitations. Missing values are not zero. Demo records never silently replace public observations.

## Research workflow

`public source -> immutable snapshot -> validation/quarantine -> normalized record -> derived indicator -> analytical view -> optional model input -> versioned output`

The public platform contains methods and aggregate public-safe artifacts only. It contains no unpublished paper manuscript, private reviewer material, credentials, restricted microdata or local paths.
