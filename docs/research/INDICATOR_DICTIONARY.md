# Indicator dictionary

NEXORA indicators are research descriptors, not universal performance scores.

| Indicator | Formula / construction | Interpretation boundary |
|---|---|---|
| research growth | `(works_t / works_t-1) - 1` within a declared frame | frame-dependent; publication delay applies |
| revealed specialization | region topic share / reference topic share | relative concentration, not quality or impact |
| collaboration density | observed undirected ties / possible ties | depends on node frame and edge definition |
| bridge dependence | share of shortest paths or flow using declared bridge nodes | descriptive network vulnerability; not causal |
| evidence coverage | documented available fields / declared required fields | completeness of evidence, not truth score |
| freshness | retrieval date minus latest source observation date | provider cadence and revisions must be shown |
| policy instrument mix | records by explicit instrument classification | policy activity, not effectiveness |
| simulated trajectory delta | scenario final value minus baseline final value | conditional model result, not forecast |

All charts must display denominator/frame, geography, time range, evidence class and version where space permits, with full details in methods/provenance.
