# Research support matrix

This public matrix describes platform capability, not unpublished paper content.

| Capability | Public platform | Private research use | Publication claim status |
|---|---|---|---|
| public provider registry | available | source planning | descriptive only |
| variable/indicator dictionaries | available | operationalization | definitions, not findings |
| data provenance and quality | available | audit trail | coverage-specific |
| geographic and network views | available | exploratory analysis | frame-dependent |
| policy mechanism taxonomy | available | scenario design | activity/mechanism, not effectiveness |
| model v1 simulator | available | exploratory baseline | conditional, partially calibrated |
| model v2 specification | available | research design | conceptual; not forecasting |
| aggregate public exports | available | reproducible inputs | no restricted/private data |
| manuscript/reviewer materials | prohibited | private only | never public before authorization |

No NEXORA page is itself peer review. Findings require an appropriate research design, transparent limitations and independent scholarly review.
