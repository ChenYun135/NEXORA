# Data freshness

**Data checked: August 2026. Latest source updates vary by provider.**

NEXORA uses the following public-facing states:

- **Current** — the last verified snapshot is within its provider-specific freshness window.
- **Updated this month** — a new verified official release or revision was promoted.
- **No new official release** — the monthly check succeeded, but the provider has not published a newer native release.
- **Stale** — the last verified snapshot is older than its declared freshness window.
- **Temporarily unavailable** — a provider check is degraded; the last known good snapshot remains in service.
- **Not configured** — an optional source is awaiting credentials or controlled setup and is skipped safely.
- **Review required** — the source requires manual verification before any public promotion.

Provider-level checked and updated dates, coverage, native cadence, snapshot ID, and official source are published in the Data Status experience and machine-readable registry.
