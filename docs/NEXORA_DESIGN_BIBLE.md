# NEXORA Design Bible / 设计规范

NEXORA combines analytical density with calm global exploration. The visual language uses midnight navy rather than black, restrained electric blue, violet, cyan, magenta, and amber, subtle borders, low-opacity surfaces, precise typography, data grids, and measured glow.

NEXORA 将高密度分析与沉静的全球探索感结合。视觉使用深海军蓝而非纯黑，并克制地运用电光蓝、紫罗兰、青色、洋红与琥珀色；卡片采用细边框、低透明度表面、精确排版与柔和光晕。

Avoid generic SaaS patterns, robot imagery, cartoon styling, gaming cyberpunk, and ornamental icon overload. Motion communicates live systems and respects reduced-motion settings. Desktop is primary; mobile restructures content rather than shrinking it.
