# Simulation Uncertainty / 模拟不确定性

Four uncertainty classes are shown separately:

1. Evidence uncertainty: sparse or proxy observations.
2. Structural uncertainty: equations and feedback topology may omit mechanisms.
3. Parameter uncertainty: most coefficients are expert/model assumptions within review ranges.
4. Scenario uncertainty: interventions and external conditions are conditional narratives.

Monte Carlo simulation is deliberately deferred. Defensible probability distributions, correlations, and production outcome histories are unavailable; inventing them would create false precision. Current one-way sensitivity is transparent but is not a probability interval.
