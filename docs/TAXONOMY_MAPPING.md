# Taxonomy Mapping / 分类映射

External taxonomies map into, never replace, NEXORA's nine industries and technology themes. `openalex-topics.ts` supports one-to-many mappings, manual overrides, version, confidence and bilingual notes. `patent-taxonomy.ts` supports CPC/IPC include/exclude rules and review status. Mapping changes create a new version; prior metric results retain their original version.
