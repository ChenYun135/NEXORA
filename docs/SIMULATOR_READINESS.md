# Simulator Readiness

Sprint 8 establishes reusable inputs for a future Sprint 9 Scenario Simulator: stable entity IDs, typed query plans, metric/time-series evidence, explicit snapshots, provenance, deterministic data sufficiency, uncertainty, conflicts, and versioned answer metadata.

Not yet ready for simulation: causal models, intervention variables, calibrated parameter ranges, back-testing, confidence intervals, scenario persistence, and policy-effect estimation. Sprint 8 does not simulate or forecast. A future simulator must preserve the same production/Demo separation and must label assumptions separately from observations.
