# Public License and Reuse Audit

Date: 2026-08-11

| Material | Public use decision | Attribution/constraint |
|---|---|---|
| Original NEXORA code/docs | Include | MIT; copyright Yun Chen |
| OpenAlex selected public records/aggregates | Include with provenance | OpenAlex states its dataset is CC0; preserve source links and retrieved/freeze semantics |
| World Bank indicators | Include selected values | Generally CC BY 4.0; attribute World Bank, no endorsement, respect third-party exceptions |
| U.S. federal Data.gov-linked records | Dataset-specific | Most federal data is public domain, but each dataset's access/use metadata controls |
| BLS selected statistics | Include with attribution | Most BLS information is public domain; copyrighted photos/illustrations are exceptions and are not redistributed |
| NSF public award records | Include selected records | Cite NSF source; public availability alone does not waive dataset-specific notices |
| USPTO data | Not configured / not redistributed | Keep patent metrics NOT_SUPPORTED until source, key, terms, and construct validation pass |
| Fonts | Include only locally bundled open font files | Preserve upstream license files; current UI also has system fallbacks |
| Third-party logos/marks | Exclude unless necessary | Names may identify sources; no implied affiliation or endorsement |

The MIT license covers only original NEXORA software/documentation. It does not relicense third-party data, marks, or linked content. Public source terms must be rechecked when adding a provider or materially changing redistributed fields.
