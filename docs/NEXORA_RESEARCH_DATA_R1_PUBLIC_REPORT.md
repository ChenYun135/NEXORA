# NEXORA Research Data Expansion R1 — Public Report

## Public result

R1 establishes a source-first public data foundation covering 20 official provider families across scholarly research, public R&D, talent, entrepreneurship, patents, collaboration, policy and regional economic context.

The release adds a canonical provider registry, semantic missing-value states, frozen snapshot manifests, a generic region-year schema, versioned occupational and policy-instrument taxonomies, a controlled public program library, data quality tests and public documentation. Provider states remain conservative: an entry is not marked ready merely because an API or download exists.

## Boundaries

The public release contains only generic provider infrastructure and public-safe documentation. All unpublished analytical artifacts remain outside the public release, and the simulator remains generic.

## Current gaps

Several Tier A sources remain staged or not configured pending live ingestion, source-license review, key configuration, geography/institution crosswalk QA and frozen-snapshot promotion. Private-capital evidence remains unavailable rather than being replaced with proprietary or speculative data.
