# Data Sources / 数据来源

Preferred production sources include OpenAlex, USPTO Open Data, World Bank Open Data, Data.gov, official government portals, university and research institution sources, and official company disclosures.

优先生产数据源包括 OpenAlex、USPTO Open Data、世界银行开放数据、Data.gov、政府官方网站、大学与科研机构来源，以及企业官方披露。

This sprint integrates no live APIs. `data/demo/` contains prototype-only structured records and the interface labels them accordingly.
