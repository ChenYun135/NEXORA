# Simulator Calibration / 模拟器校准

Calibration snapshot version: `sim-calibration-2026-08-10`.

Of nine initial stock concepts, one (11.1%) is observed-calibrated, one (11.1%) is derived-calibrated, and seven (77.8%) are assumption-led. The observed series is mapped OpenAlex topic publication counts for 2020–2025. The knowledge initialization is a versioned cumulative/lagged derivation of that series. World Bank R&D expenditure is retained only as country-level context; it is not metro calibration.

Verified public policy/program and organization identities establish context, not intervention magnitude or causal effect. One verified relationship cannot calibrate an ecosystem network. Sprint 4–6 Demo values are explicitly excluded.

Unavailable patent, capital, startup, commercialization, talent, adoption, infrastructure-effect, and policy-effect series remain unavailable. Missing values are never coerced to zero. Recalibration requires a new immutable snapshot, validation record, model changelog entry, and review.
