# Simulator Model Validation / 模型验证

Automated validation covers model/version identity, typed stock/flow counts, equation dependencies, parameter defaults and ranges, scenario completeness, 5/10/15-year horizons, determinism, finite/non-negative bounded outputs, delay behavior, directional sanity checks, invalid-input rejection, baseline comparison, sensitivity ordering, calibration coverage, and export metadata.

Validation establishes internal consistency and regression safety. It is not empirical validation. External validation and back-testing remain blocked by missing longitudinal production outcomes. Any clamp, assumption-heavy context, missing patents, sparse contextual coverage, or out-of-review input produces an explicit warning.
